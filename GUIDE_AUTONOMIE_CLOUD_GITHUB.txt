================================================================================
  GUIDE D'AUTONOMISATION DU MOTEUR 24H/24 DANS LE CLOUD (SANS AUCUN PC ALLUMÉ)
================================================================================

Si vous êtes en déplacement, en voyage, ou que votre PC est éteint,
vous pouvez faire tourner votre moteur 100% GRATUITEMENT dans le Cloud grâce à
GitHub Actions.

FONCTIONNEMENT :
----------------
1. Votre code tourne sur les serveurs sécurisés de GitHub.
2. Chaque jour à 08h30 GMT, 13h00 GMT et 21h30 GMT, GitHub lance le moteur,
   calcule les prédictions et publie automatiquement sur https://prono.elite-turf.fr.
3. Vous n'avez plus besoin d'avoir votre ordinateur allumé.

MISE EN PLACE EN 3 ÉTAPES SIMPLES (5 MINUTES) :
------------------------------------------------
1. Créez un compte gratuit sur https://github.com si vous n'en avez pas encore.
2. Créez un dépôt (Repository) privé nommé "turf-engine".
3. Déposez-y tous les fichiers de votre dossier "TURF PROJET" (y compris le dossier .github).
4. Dans votre dépôt GitHub > Settings > Secrets and variables > Actions :
   - Ajoutez le Secret "CLOUDFLARE_API_TOKEN" (votre jeton Cloudflare).
   - Ajoutez le Secret "CLOUDFLARE_ACCOUNT_ID" (bfb7a27738f18d7e642980d343a69ee8).

C'est terminé ! Votre moteur tourne désormais 24h/24 dans le cloud de manière
totalement autonome.
