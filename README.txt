========================================================================
  TURF PREDICTION ENGINE & BANC DE MESURE (Windows)
========================================================================

CONTENU DU DOSSIER :
- turf_lab/           : Modules Python (database, features, engine, baselines, benchmark, simulator)
- main.py             : Script principal d'orchestration
- run_benchmark.bat   : Fichier exécutable par double-clic sous Windows

INSTALLATION RAPIDE :
1. Assurez-vous d'avoir Python installé sur Windows (https://www.python.org).
   IMPORTANT : Cochez impérativement la case "Add Python to PATH" pendant l'installation.
2. Double-cliquez simplement sur le fichier "run_benchmark.bat" pour lancer le banc de mesure.
3. Les résultats comparatifs s'afficheront dans la fenêtre et seront sauvegardés dans "benchmark_report.json".
